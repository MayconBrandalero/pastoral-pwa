# PWA de Acompanhamento Nutricional Infantil — Pastoral da Criança

Protótipo de aplicativo desenvolvido em **Angular (Standalone)** e **Angular Material** configurado como Progressive Web App (PWA), criado para auxiliar voluntárias da Pastoral da Criança no registro e acompanhamento nutricional de crianças em comunidade.

## 📱 Funcionalidades do MVP (Fluxo de Telas)
1. **Tela de Busca (Menu Principal):** Permite localizar rapidamente fichas de crianças cadastradas ou iniciar um novo registro através de um botão flutuante.
2. **Tela de Formulário (Registro de Pesagem):** Coleta rápida de dados antropométricos essenciais (peso em kg e altura em cm) com validação de entradas.
3. **Tela de Resultado e Histórico:** Confirmação visual de salvamento em modo offline e exibição do histórico nutricional comparativo.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** Angular (Standalone Components)
- **UI Framework:** Angular Material
- **PWA:** Angular Service Worker (`@angular/pwa`)
- **Controle de Versão:** Git & GitHub
